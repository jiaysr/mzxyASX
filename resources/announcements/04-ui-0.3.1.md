# v0.3.1 更新说明

## 登录 / 启动页对齐旧版

- 登录页改成「服务地址 + 登录」，右下角圆形按钮进入启动页
- 新增独立启动页：脚本目录选择/校验、deploy.yaml 编辑、启动日志、启动/停止
- 启动配置区默认收起，启动日志直接留在首屏
- 修复启动时白屏：自动连接改为后台单次判断，不再阻塞首屏
- 修复启动/停止悬浮按钮图标不居中

## 脚本引擎

控制台不再下载 code/env 包，改为运行脚本目录里的 `deploy.installer`：

- 从 mzxyAutoScript Releases 下载 `mzxyAutoScript-easy-install` 分卷并解压到控制台安装目录之外
- 在启动页选择目录，首次启动会 `git pull` + `pip install`
- 控制台数据固定在 `%LOCALAPPDATA%\mzxy`，UI 更新/重装不会搬运或删除脚本目录
- 旧版 `engine\code|env` 发布包不再支持，请重新选择完整脚本目录
