# 使用须知

## 关于本工具

明珠轩辕脚本控制台负责界面、脚本目录管理和进程启停；脚本逻辑在
[mzxyAutoScript](https://github.com/jiaysr/mzxyAutoScript) 仓库。
脚本的安装与更新由脚本目录里的 `deploy.installer`（git pull + 依赖）完成，控制台不下载引擎包。

## 数据在哪

控制台自己的配置和缓存放在安装目录（整个文件夹拷走就能换机器）；
脚本的配置和日志在用户选择的脚本目录里。

## 脚本

首次使用需要先准备一个完整的脚本目录（含 toolkit、module、deploy），
在登录页或「设置 → 脚本服务」里选择它，再点「启动脚本服务」。
启动前会先执行 `deploy.installer`，可以在「更新设置」里关闭这一步。

关闭应用会一并停止脚本服务；如果应用被强制结束，下次启动会自动清理残留的引擎进程。
