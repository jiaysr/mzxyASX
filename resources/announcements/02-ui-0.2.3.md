# v0.2.3 更新说明

## 新增「战斗」页

脚本配置的二级菜单里多了「战斗」，可以直观地管理技能顺序和预设：

- 卡片式技能列表，**拖拽调整释放顺序**，也可以悬停用 ↑ / ↓ / 置顶
- 预设管理：新建（可基于已有预设）、重命名、删除、恢复默认顺序；系统预设锁定不可改
- 批量操作：勾选多个技能一次性启用 / 禁用；顶部实时显示「启用 N / 20」
- 右侧可以调识别相似度、是否只点冷却好的技能、技能点击间隔
- 「识别当前技能栏」会连设备截图，显示 7 个技能位的识别分数和开战时的释放顺序

任务参数里的「战斗配置」现在会列出所有预设，直接下拉选择即可。

## 其他改进

- 手动启动的脚本服务现在能正常连接了（之前会被误判成本机引擎已停止而清掉地址）
- 「设置 → 脚本服务」新增「启动引擎」，引擎停掉后不用退出登录再重开
- 战斗配置等改动保存后会有「已保存 / 保存失败」提示
- 脚本运行中会禁止重命名或删除该配置，避免正在跑的任务被打断
- 更新安装时会保留引擎、配置、日志和缓存，不再需要重新下载引擎
